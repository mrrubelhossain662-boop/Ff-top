# Ff-top API Reseller & Panel System

এই প্যাকেজে আপনার `Ff-top` প্রজেক্টে ডাইনামিক এপিআই ও প্রোডাক্ট ওভাররাইড সিস্টেম যুক্ত করার জন্য প্রয়োজনীয় ফাইলগুলো দেওয়া হয়েছে:

১. `database.sql`: ডাটাবেসে টেবিল তৈরির জন্য স্কিমা।
২. `admin_api.php`: অ্যাডমিন প্যানেল যেখানে নতুন এপিআই সোর্স (URL & Token) যুক্ত করা যাবে।
৩. `frontend_panel.php`: ইউজার প্যানেল যেখানে ডায়নামিক বাটন এবং এপিআই থেকে আসা অফারগুলো কাস্টম প্রাইস ও ইমেজসহ শো করবে।

### ইন্সটলেশন গাইড:
- আপনার ডাটাবেসে `database.sql` ফাইলটি ইম্পোর্ট করুন।
- আপনার প্রজেক্টের অ্যাডমিন ফোল্ডারে `admin_api.php` এবং ফ্রন্টএন্ডে `frontend_panel.php` যুক্ত করুন।
- cURL বা Axios এর মাধ্যমে থার্ড-পার্টি এপিআই কল করে প্রোডাক্ট রেন্ডার করুন।
